# Evaluation rubric

Score each category from 0–2; passing score is 8/10 with no zero.

1. **Core behavior** — creation, checklist toggling, deletion, progress, and readiness work correctly.
2. **Persistence and resilience** — records survive reloads; malformed storage fails safely.
3. **User experience** — search/filter, responsive layout, empty states, clear feedback, and keyboard access.
4. **Engineering quality** — strict TypeScript, maintainable boundaries, meaningful tests, lint/build success, coverage >=80%.
5. **Production handoff** — hardened Docker runtime, CI/CD, VPS deployment/rollback instructions, architecture and contribution docs.
